# georgiansarghi/homebrew-tap

Homebrew casks for [TextPicker](https://github.com/georgiansarghi/TextPicker).

## Install

```sh
brew install --cask georgiansarghi/tap/textpicker
```

TextPicker isn't notarized, so on first launch allow it in
**System Settings → Privacy & Security → Open Anyway**.

## Update

```sh
brew upgrade --cask textpicker
```

The cask is bumped automatically when a new TextPicker release is published.
